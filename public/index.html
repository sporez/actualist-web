Actualist

A native, local-first iPhone client for Actual Budget.

It connects to a normal Actual sync server, imports the budget into SQLite on the phone, and reads from that copy. Offline edits sit in an outbox until the server is reachable again. Companion to Actual — not a second backend, and not a webview.

Join the TestFlight Source on GitHub

The TestFlight build can open a bundled demo budget if you don’t have a server yet.

Screenshots use randomized display values.

Your server, not ours

Actualist talks to the Actual sync server you already run. There is no Actualist cloud, no analytics SDK, and no developer-operated backend. After the first import, the app opens the local copy first, then syncs Actual CRDT messages in the background.

Encrypted budgets unlock on the phone. Sync tokens and keys stay in the iOS Keychain. Budget files live in the app’s private container and are kept out of iPhone and iCloud backups on purpose — the server is the copy that matters once an upload has finished.

On the phone

Budget
Monthly category groups, assigned and available amounts, To Budget, uncategorized transactions, and overspent alerts. Assign money, move it, roll categories over, hide or show categories, add and edit budget templates, and add notes.
Spending
A feed across accounts, plus searchable history on each one. Create, edit, delete, categorize, split, and transfer.
Accounts
On-budget, off-budget, and closed, with the order you set on this device, plus account notes. Account groups appear when the Actual server supports them.
Reports
Net worth, cash flow, month-to-month, spending averages, and activity. Native charts, not a wrapped website.
Rules & payees
Common Actual payee-rule conditions, field-setting actions, and imported split rules stay in sync with the server. Split rules stay read-only in the editor. Unsupported shapes stay visible so their JSON is never rewritten.
Bank Sync
Link SimpleFIN through your server or a device token, review downloads, then save. Apple Wallet import lives on the same Settings page. Background Bank Sync stays off under Advanced.
The rest of the device
Density and themes (including Actual Purple), a privacy cover, background refresh, Shortcuts, and Siri. HTTPS is preferred; local HTTP is allowed only on trusted networks, with a warning first.

What it doesn’t do

  • Bank Sync is SimpleFIN only. Other bank providers still arrive after another Actual client or the server imports them. Background Bank Sync is experimental and off by default.
  • Account reconciliation is not in yet, and closing, renaming, or deleting accounts is still incomplete.
  • Budget templates can be created and edited, and Apply Template previews the assignments before saving. Some template types, and templates written in a category note, stay view-only. Applying one can change many assignments at once — back up first.
  • Actualist is an independent community project. It is not affiliated with or endorsed by Actual Budget.

What you need

  • An iPhone on iOS 26 or later
  • A running Actual Budget server with at least one budget already uploaded for sync — unless you’re only opening the demo
  • The server password, or OpenID if the server uses it, and the budget encryption password if you use one
  • A network path to that server. If it only lives on a VPN or Tailscale, join that network on the phone first
!

Beta software, real money

Actualist can modify financial data. Export and verify an Actual backup before you test, and don’t treat the phone as the only copy. Public builds are tagged testflight/v<version>-b<build> so the source matches what you installed. Found a problem? Open an issue and attach a diagnostic report from Settings — it strips credentials and amounts.
