Actualist

A native, local-first iPhone and iPad client for Actual Budget.

Connect to your Actual Budget server and keep your budget on your device for quick access, even offline. Changes sync when your server is reachable again. Review spending, manage transactions, and plan your month in a native app.

Join TestFlight Source on GitHub

The TestFlight build can open a bundled demo budget if you don’t have a server yet.

Screenshots use randomized display values.

Your server, not ours

Actualist talks to the Actual sync server you already run. There is no Actualist cloud, no analytics SDK, and no developer-operated backend. After the first import, the app opens your saved budget immediately and checks for updates in the background. If you configure a SimpleFIN device token, bank downloads connect directly to SimpleFIN.

Encrypted budgets unlock on your device. Sync tokens, unlocked budget keys, and custom request headers stay in the iOS Keychain. Budget files and financial widget snapshots are excluded from local and iCloud device backups. Your server can restore changes that have finished syncing; pending changes can be lost if you erase the app or lose the device.

In the app

Budget
Envelope and tracking budgets with category groups, uncategorized transactions, and overspending alerts. Envelope budgets show Assigned, Available, and To Budget, with Move Money. Tracking budgets show Budgeted, Balance, income received, and savings summaries. Roll categories over, hide or show them, add and edit templates, and keep notes.
iPad
Sidebar navigation, category details, keyboard assignment, and up to five budget months side by side. Compact layouts can use Swipe Between Months for full-width month transitions.
Spending
A feed across accounts, plus searchable history on each one. Create, edit, delete, categorize, split, and transfer.
Accounts
On-budget, off-budget, and closed, with the order you set on this device, plus account notes. Add accounts, and reconcile them from an account’s transaction screen: enter a bank balance or use Last Balance from Bank, review the cleared difference, create an adjustment, and lock balanced transactions. Reconciled edits and deletes require confirmation. Manage groups and move accounts between them when your Actual server supports groups.
Reports
Net worth, cash flow, month-to-month, spending averages, and activity. Native charts, not a wrapped website.
Rules & payees
Search, create, edit, and delete supported rules in Settings → Budget & Data, with previews of matching transactions. Imported split rules apply to transactions but remain read-only in the editor.
Bank Sync
Link SimpleFIN through your server or a device token, review downloads, then save. Apple Wallet import lives on the same Settings page. Optional Background Bank Sync is in Settings → Budget & Data → Bank Sync. It is off by default and downloads and saves changes automatically when enabled.
History
Open History from the Budget ⋯ menu to see the last 25 changes made on this device. Review and undo the most recent eligible budget assignment, money move, template application, or transaction change.
Widgets
Category and account balances, Needs Attention, Month Overview, Recent Transactions, Net Worth, and Quick Actions. Choose supported actions, accounts, and categories in Edit Widget. Widgets follow your Appearance theme and budget type.
Connection & sync
Password or OpenID sign-in, encrypted budgets, primary and fallback servers, and Custom Headers for servers that require them. Test a connection before saving its Keychain-protected headers.
The rest of the device
Density and themes (including Actual Purple), a privacy cover, background refresh, Shortcuts, and Siri. HTTPS is preferred; local HTTP is allowed only on trusted networks, with a warning first.

What it doesn’t do

  • Bank Sync is SimpleFIN only. Other bank providers still arrive after another Actual client or the server imports them. Background Bank Sync is experimental and off by default.
  • You can add and reconcile accounts, but renaming, closing, reopening, and deleting accounts are not yet supported.
  • Templates written in category notes remain read-only. Some advanced template types and options cannot be edited here.
  • Creating, renaming, deleting, and reordering categories still require another Actual client.
  • Some imported rules, including split rules, cannot be edited here.
  • Actualist is an independent community project. It is not affiliated with or endorsed by Actual Budget.

What you need

  • An iPhone or iPad running iOS or iPadOS 26 or later
  • A running Actual Budget server with at least one budget already uploaded for sync — unless you’re only opening the demo
  • The server password, or OpenID if the server uses it, and the budget encryption password if you use one
  • A network path to that server. If it only lives on a VPN or Tailscale, join that network on the device first
!

Beta software, real money

Actualist can modify financial data. Export and verify an Actual backup before you test, and don’t treat one device as the only copy. Public builds are tagged testflight/v<version>-b<build> so the source matches what you installed. Found a problem? Open an issue and attach a report from Settings → Support → Share Diagnostic Report. Review attachments and remove personal information from screenshots before sharing.
